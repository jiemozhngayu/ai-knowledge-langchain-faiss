# 本地知识库方案说明

LangChain 负责文档对象、文本切分与嵌入客户端；FAISS 负责本地向量召回；Ollama 运行向量模型、重排模型和回答模型。
FastAPI 提供入库、检索与问答接口；Streamlit 提供中文演示页面；SQLite 保存文件目录和操作日志。

知识片段保留来源、页码和访问范围。FAISS 召回后先过滤访问范围，再向本地重排模型与回答模型提供已授权资料。
新索引先在临时目录生成，完成后切换，以降低重建失败对当前索引的影响。

本仓库只包含虚构演示语料和源代码。数据库、索引、真实资料、飞书同步快照均在使用者本机生成或保存，默认不进入 Git。
演示身份切换和请求头不提供真实认证；上线前需完成服务端身份验证。

验收可使用住宿报销、财务付款审批和无关问题：核对来源、验证部门资料隔离，并检查无匹配资料时是否拒答。
重排参考分不能作为答案正确率。当前相关度阈值需要按实际资料与问题集重新校准。
